## About me

I build things that work in the real world: full-stack web apps, AI agents and automation workflows that save teams time.

My core is the **MERN stack**. I build React frontends, Node.js and Express backends, and MongoDB databases, with real-time features, secure authentication and clean REST APIs. My messaging app Synas, with offline sync and 500MB file sharing, shows how I think: plan first, then build carefully.

On top of that, I add **AI and automation**. I integrate OpenAI, Claude and Mistral into products, build AI agents, and design n8n, Make and Zapier workflows that handle lead capture, CRM syncing and content publishing without manual work.

I also deliver **WordPress and WooCommerce** websites for international clients, built to load fast, look sharp on every screen and rank well.

I use AI tools like Cursor, Claude and ChatGPT every day to move faster, but I review and test every piece of code I ship. I communicate clearly with clients, learn new tools quickly, and care about reliable, maintainable work.
